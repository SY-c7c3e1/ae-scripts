# Groups to Layers

Illustrator用スクリプト。1つのレイヤーの中にあるグループを、グループ1個ずつ
別々のレイヤーへ分割する。

Illustrator標準の「レイヤーに分配」はレイヤー内の全オブジェクトが対象になるが、
このスクリプトは**グループだけ**を対象にする。グループ以外のオブジェクト
（パス・テキストなど）はそのまま元のレイヤーに残る。

## 使い方

1. Illustratorでドキュメントを開く
2. `GroupsToLayers.jsx` を実行（File → Scripts → Run Script File…）
3. ドロップダウンから対象レイヤーを選ぶ（サブレイヤーも階層表示で選べる）
4. 必要なら「選択中のグループのみ処理する」をON
   （OFFの場合、そのレイヤー直下にある全グループが対象）
5. [実行] を押す

新しく作られるレイヤーは元のレイヤーのすぐ上に積まれ、グループ同士の
前後関係（重なり順）は分割後も維持される。

## 名前について

- グループに名前が付いている場合は、その名前がそのまま新しいレイヤー名になる
- 名前が未設定（空欄）の場合は「元レイヤー名_1」のように自動採番される
- 名前が重複する場合は末尾に " (2)" のように連番を付けて区別する

## 注意

- 対象にできるのは、選んだレイヤーの**直下**にあるグループのみ（グループの
  中にネストされたグループは対象外）
- 対象レイヤーがロックされている場合はロックを解除してから実行する
- 「処理後に元レイヤーが空なら削除する」がONで、かつ元レイヤーに何も残らな
  かった場合は、元レイヤー自体が削除される
