# SplitByDistance.jsx（日本語）

1枚の画像レイヤーに複数の離れたオブジェクト（宝石、アイコンなど）がまとまっている
場合、それぞれを**個別のコンポジションに自動で振り分ける**スクリプトです。

対象レイヤーを選択して実行すると、AE純正の「オートトレース」機能が自動で開き、
そこで検出された図形（宝石やアイコンなど）ごとに、その形状で正確にクロップされた
新規コンポジションが作成されます。

---

## インストール

`SplitByDistance.jsx` と `SplitByDistance.core.js` の2つを、以下のフォルダに
**まとめて**置いて、After Effects を再起動してください。

```
C:\Program Files\Adobe\Adobe After Effects <バージョン>\Support Files\Scripts\
```

**ファイル → スクリプト → スクリプトを実行…** から起動します。

> `Scripts\ScriptUI Panels\` に置けばパネルとして常駐できます。

---

## 使い方

1. 複数のオブジェクトがまとまっている画像レイヤーを選択する
2. `SplitByDistance.jsx` を開く
3. 「コンポの余白」（デフォルト 10px）などを設定
4. **[実行]** をクリック
5. AEの「オートトレース」ダイアログが自動で開くので、設定して **OK**
   （チャンネルは、背景が透明な画像なら「アルファ」がおすすめです）
6. オートトレースで新しく作られたマスクごとに、その図形の形状でクロップされた
   新規コンポジションが作成されます

オートトレースのダイアログで **キャンセル** すると、何も作成されずに終了します。

---

## 判定方法

このスクリプトは、**実行の直前と直後でレイヤーのマスク数を比較**し、新しく
追加されたマスクだけを対象にします（実行前から付いていたマスクには影響しません）。

各マスクのパス頂点からバウンディングボックス（レイヤーローカル座標系）を求め、
コピー先の新規コンポでは、そのマスク以外はすべて削除し（無効化ではなく削除）、
残った1つを「加算」モードで有効化します。これにより、矩形クロップではなく、
検出した図形の輪郭どおりに正確にクロップされたコンポが得られます。マスクを
削除しているため、図形の数が多い場合（数十〜）でも、各コンポのレイヤーが
使わないマスクを大量に持ち歩かずに済み、動作が軽くなります。

判定は**実行時の再生ヘッド位置**（コンプの現在時間）を基準に行われます。
レイヤーが動くアニメーションの場合は、分割したい状態のフレームに再生ヘッドを
合わせてから実行してください。

## オプション

| オプション | 説明 |
|---|---|
| コンポの余白 (px) | 各コンポの周りに残す余白（デフォルト 10px） |
| コンプ名の接頭辞 | 生成されるコンポ名の先頭に付ける文字列（空欄ならアクティブコンプ名を使用） |
| 生成したコンポをフォルダにまとめる | ON（デフォルト）: プロジェクトパネルに専用フォルダを作成してまとめる |
| 元レイヤーを削除する（移動モード） | OFF（デフォルト）: 元コンポのレイヤーはそのまま残る（複製） / ON: コピー後に元レイヤーを削除（移動） |

## 制限事項・注意点

- **オートトレースの自動実行**：メニューコマンドが見つからない、または実行できない
  場合はエラーになります。その場合は、手動で メニュー → レイヤー → オートトレース...
  を実行してからもう一度スクリプトを実行してください（すでにあるマスクは対象外なので、
  その状態でも正しく動きます）。
- **マスクパスの頂点のみ**からバウンディングボックスを計算します。ベジェのハンドルが
  頂点より外側に大きく膨らんでいる場合、その分は範囲に含まれないことがあります
  （通常のオートトレース結果ではほぼ問題になりません）。
- 反転しているマスクは無視されます。
- **3Dレイヤー**：X/Y位置とZ回転のみを考慮した簡易的な2D近似で計算します。X/Y回転や
  カメラ・パースの影響は考慮されないため、結果がズレる場合は完了後のアラートに表示される
  警告一覧を確認し、手動で調整してください。
- **親子関係**：レイヤーに親が設定されている場合、コピー後の自動位置調整はスキップされます
  （警告として表示されます）。親子関係を使ったレイアウトは、あらかじめプリコンポーズしてから
  実行することをおすすめします。
- **Position のエクスプレッション**：Position にエクスプレッションが設定されている場合も
  自動位置調整はスキップされます。
- 新規コンポの長さ・フレームレート・ピクセル縦横比は、元コンポの設定を引き継ぎます。
- Undo（Ctrl+Z）に対応しています（1回の実行がひとつのUndoグループにまとまっています）。
- 「移動モード」はレイヤーを削除する操作です。心配な場合はプロジェクトを別名保存してから
  実行してください。

## 使用例

添付のような、宝石やアイコンなど複数のオブジェクトが**1枚の画像（1レイヤー）**として
まとまっている場合：

1. その画像レイヤーを選択する
2. 余白を設定して **[実行]**
3. 開いたオートトレースのダイアログで、チャンネル＝アルファ（背景が透明な場合）等を
   設定してOK
4. 図形ごと（例：宝石1つずつ）に、その形状でクロップされた新規コンポが作成される
