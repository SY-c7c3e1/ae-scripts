# MarkerCopy.jsx

After Effects のマーカーをクリップボード方式でコピー＆ペーストするスクリプト。
レイヤーマーカー・コンポマーカーをまたいで、または別コンポ間でも自由にコピーできます。

---

## インストール

`MarkerCopy.jsx` を以下のフォルダに置いて、After Effects を再起動してください。

**Windows**
```
C:\Program Files\Adobe\Adobe After Effects <バージョン>\Support Files\Scripts\
```

**Mac**
```
/Applications/Adobe After Effects <バージョン>/Scripts/
```

After Effects のメニュー **ファイル → スクリプト → スクリプトを実行…** から `MarkerCopy.jsx` を選んで実行します。

> ScriptUI Panels フォルダに置けばウィンドウメニューからパネルとして常駐させることもできます。

---

## 基本の使い方

操作は **Copy → Paste** の2ステップだけです。

### Step 1 — Copy

| コピー元 | 操作 |
|---|---|
| レイヤーマーカー | コピーしたいレイヤーを選択して **[Copy]** |
| コンポマーカー | レイヤーを選択せずに **[Copy]** |
| 複数レイヤー | 複数レイヤーを選択して **[Copy]**（マーカーは統合されます） |

コピーが成功するとパネルの「クリップボード」欄にコピー元の名前とマーカー数が表示されます。
クリップボードの内容はパネルを閉じるまで保持されます。

### Step 2 — Paste

| ペースト先 | 操作 |
|---|---|
| レイヤーマーカー | ペーストしたいレイヤーを選択して **[Paste]** |
| コンポマーカー | レイヤーを選択せずに **[Paste]** |
| 複数レイヤーに一括 | 複数レイヤーを選択して **[Paste]** |

別のコンポに移動してからペーストすれば、コンポをまたいだコピーもできます。

## オプション

### 現在位置にペースト
コピーしたマーカー群の**先頭マーカー**がタイムラインの現在位置（再生ヘッド）に来るよう、全体の時刻をまとめてシフトしてペーストします。

- **OFF（デフォルト）** — 元の絶対時刻のままペースト
- **ON** — 再生ヘッドの位置を起点にペースト

別のコンポや別のタイミングに同じマーカーパターンを流用したいときに便利です。

### 既存マーカーを保持（追記）
- **OFF（デフォルト）** — ペースト先の既存マーカーをすべて削除してから貼る（上書き）
- **ON** — 既存マーカーはそのままにして追記する

### レイヤーのイン点をオフセットに使う
- **OFF（デフォルト）** — コンポの絶対時刻でコピー／ペースト
- **ON** — レイヤーのイン点を基準にした相対時刻でコピー／ペースト。ループ素材など、レイヤーの開始位置を0として扱いたい場合に使います。

## 使用例

### レイヤーマーカー → コンポマーカー
1. マーカーが付いているレイヤーを選択 → **[Copy]**
2. レイヤーの選択を解除 → **[Paste]**

### コンポマーカー → 別コンポのコンポマーカー
1. コピー元コンポで（レイヤー未選択）→ **[Copy]**
2. コピー先コンポのタブをクリックしてアクティブにする
3. （レイヤー未選択）→ **[Paste]**

### 同じコンポ内でレイヤーマーカーを複製
1. コピー元のレイヤーを選択 → **[Copy]**
2. コピー先のレイヤーを選択 → **[Paste]**

### 再生ヘッドの位置からペースト
1. マーカーをコピー
2. ペースト先で再生ヘッドを置きたい位置に移動
3. **「現在位置にペースト」にチェック** → **[Paste]**

---

## 注意事項

- コピーされるマーカー情報：コメント、デュレーション、チャプター、URL、フレームターゲット、キューポイント名、ラベル
- クリップボードはパネルを閉じるとリセットされます
- Undo（Ctrl+Z / Cmd+Z）に対応しています
