# SplitByDistance.jsx（日本語）

コンポ内に散らばって配置されたレイヤー（バラバラに置かれた図形やアイコンなど）を、
**近くにあるもの同士でグループ化**し、グループ（＝離れたオブジェクト）ごとに
自動で新規コンポジションへ振り分けるスクリプトです。

例えば、1つのコンポに複数の独立したアイコン／図形をまとめて配置してある場合、
それぞれの「かたまり」を個別のコンポとして書き出したい、という用途に使えます。

検出モードは2種類あります。

- **レイヤー単位**：コンプ内にすでに分かれている複数のレイヤーを、位置関係でグループ化する
- **ピクセル単位**：1枚のPNG画像（1レイヤー）の中身を解析し、透明部分（アルファ）や
  白・黒背景をもとに、離れたオブジェクトを自動検出してグループ化する

---

## インストール

`SplitByDistance/` フォルダの中身（`SplitByDistance.jsx`、`SplitByDistance.core.js`、
`detect-objects.js`、`png-decode.js`）を**まとめて**以下のフォルダに置いて、
After Effects を再起動してください。**ピクセル単位モードを使う場合は4ファイルすべてが
同じフォルダに必要です**（`.jsx` が同フォルダの `detect-objects.js` を呼び出します）。
レイヤー単位モードのみで使う場合は `SplitByDistance.jsx` と `SplitByDistance.core.js`
の2つだけで動作します。

```
C:\Program Files\Adobe\Adobe After Effects <バージョン>\Support Files\Scripts\
```

**ファイル → スクリプト → スクリプトを実行…** から起動します。

> `Scripts\ScriptUI Panels\` に置けばパネルとして常駐できます。

### ピクセル単位モードの追加条件

ピクセル単位モードは、画像の解析をNode.jsに委譲します。以下を満たしている必要があります。

1. **Node.js がインストールされていること**（[nodejs.org](https://nodejs.org/) から）。
   コマンドプロンプトで `node --version` を実行してバージョンが表示されればOKです。
2. 対象レイヤーが **PNG画像ファイル**から読み込まれたフッテージであること
   （シェイプレイヤー・テキストレイヤー・プリコンプ・JPEG/PSD等は非対応です）。
3. After Effects の **環境設定 → スクリプトとエクスプレッション** で
   「**スクリプトによるファイルへの書き込みとネットワークへのアクセスを許可**」が
   オンになっていること（外部コマンドを実行するために必要です）。

レイヤー単位モードはこれらの条件と無関係に、追加インストールなしで動作します。

## 使い方

### レイヤー単位モード（デフォルト）

1. 分割したいレイヤーがあるコンポジションをアクティブにする
2. （任意）対象レイヤーだけを選択する
3. 検出モードで「レイヤー単位」を選択
4. パネルで「しきい値」「余白」などを設定
5. **[実行]** をクリック

処理が終わると、検出されたグループの数だけ新規コンポジションが作成され、
各グループのレイヤーがそこへコピーされます。

### ピクセル単位モード（1枚の画像から自動検出）

1. 複数のオブジェクトが1枚にまとまっているPNG画像レイヤーを**選択する**
   （添付のような、離れた図形が並んだ1枚の画像を想定）
2. 検出モードで「ピクセル単位」を選択
3. 「背景の判定方法」（自動 / アルファ / 白背景 / 黒背景）を選ぶ
4. 「オブジェクト同士のすき間」「コンポの余白」を設定
5. **[実行]** をクリック

画像ファイルをピクセル単位で解析し、透明部分または背景色から離れた「かたまり」ごとに
新規コンポジションが作成されます。

## 判定方法

### レイヤー単位モード

各レイヤーのバウンディングボックス（コンプ座標系での外接矩形）を計算し、
ボックス同士の最短距離が **しきい値** 以下のレイヤーを同じグループとして連結します
（Union-Find によるクラスタリング）。連結はチェーン状にも伝播するため、
A-B が近く B-C が近ければ、A-C が離れていても同じグループになります。

### ピクセル単位モード

選択したレイヤーの元画像ファイル（PNG）を、`.jsx`と同じフォルダにある
`detect-objects.js`（Node.js）に渡し、画像の**全ピクセル**を対象に「背景」か
「オブジェクト」かを判定します（格子の間引きはしません＝輪郭も正確に検出できます）。

- **アルファ**：そのピクセルのアルファ値がしきい値以下なら背景
- **背景色（白／黒／自動）**：背景色との色の差がしきい値を超えたらオブジェクト

判定できたピクセルを8近傍で連結し、ひとかたまりごとにバウンディングボックスを
求めます。ここで得られたボックス群は、レイヤー単位モードと同じ「オブジェクト同士の
すき間」による距離クラスタリングにさらにかけられるため、ピクセル的にはわずかに
離れていても近ければ同じグループとしてまとめられます。

いずれのモードも、判定はパネルを開いた時点ではなく、**実行時の再生ヘッド位置**
（コンプの現在時間）を基準に行われます。レイヤーが動くアニメーションの場合は、
分割したい状態のフレームに再生ヘッドを合わせてから実行してください。

## オプション

### 検出モード

| オプション | 説明 |
|---|---|
| レイヤー単位 | 既存の複数レイヤーを、それぞれの位置関係でグループ化（デフォルト） |
| ピクセル単位 | 選択した1枚（または複数枚）の画像の中身を解析し、自動でオブジェクトを検出 |

### 対象

| オプション | 説明 |
|---|---|
| 選択レイヤーのみを対象にする | OFF: コンプ内の全レイヤーが対象 / ON: 選択中のレイヤーのみが対象（ピクセル単位モードでは常にONになります） |
| 非表示レイヤーを含める | OFF（デフォルト）: 非表示（目玉オフ）レイヤーは除外 / ON: 非表示レイヤーも対象に含める |

Null / ガイドレイヤー / 調整レイヤーは常に対象外です。

### 背景の判定方法（ピクセル単位モードのみ）

| オプション | 説明 |
|---|---|
| 自動（おすすめ） | 画像の四隅付近を見て、透明ならアルファ判定、不透明ならその色を背景色として判定 |
| アルファチャンネル | 透明部分を背景として判定 |
| 白背景 / 黒背景 | 指定した色との違いで判定（実際に透明な場合は自動でアルファ判定に切り替わります） |

### 分割の基準

| オプション | 説明 |
|---|---|
| オブジェクト同士のすき間 (px) | この距離より離れていたら、別々のコンポに分ける（デフォルト 80px） |
| コンポの余白 (px) | 各コンポの周りに残す余白（デフォルト 40px） |

パネル下部の「詳細設定を表示」をチェックすると、以下の項目も設定できます（普段は
初期値のままで問題ありません）。

| オプション | 説明 |
|---|---|
| コンプ名の接頭辞 | 生成されるコンポ名の先頭に付ける文字列（空欄ならアクティブコンプ名を使用） |
| 生成したコンポをフォルダにまとめる | ON（デフォルト）: プロジェクトパネルに専用フォルダを作成してまとめる |
| 元レイヤーを削除する（移動モード） | OFF（デフォルト）: 元コンポのレイヤーはそのまま残る（複製） / ON: コピー後に元レイヤーを削除（移動） |

## 制限事項・注意点

- **3Dレイヤー**：X/Y位置とZ回転のみを考慮した簡易的な2D近似で計算します。X/Y回転や
  カメラ・パースの影響は考慮されないため、結果がズレる場合は完了後のアラートに表示される
  警告一覧を確認し、手動で調整してください。
- **親子関係**：レイヤーに親が設定されている場合、コピー後の自動位置調整はスキップされます
  （警告として表示されます）。親子関係を使ったレイアウトは、あらかじめプリコンポーズしてから
  実行することをおすすめします。
- **Position のエクスプレッション**：Position にエクスプレッションが設定されている場合も
  自動位置調整はスキップされます。
- 新規コンポの長さ・フレームレート・ピクセル縦横比は、元コンポの設定を引き継ぎます。
- Undo（Ctrl+Z）に対応しています（1回の実行がひとつのUndoグループにまとまっています）。
- 「移動モード」はレイヤーを削除する操作です。心配な場合はプロジェクトを別名保存してから
  実行してください。

### ピクセル単位モード特有の制限

- 対応形式は **PNG画像のみ**です（8bit、非インターレース、RGB/RGBA/Grayscale/
  GrayscaleAlpha）。JPEG・PSD・パレット(インデックスカラー)PNG・16bit PNGなどは
  非対応で、実行前にエラーになります。
- 対象は **PNG画像ファイルから読み込んだレイヤー**のみです。シェイプレイヤー・
  テキストレイヤー・プリコンプなど、ファイルを持たないレイヤーは対象外です。
- 生成されるコンポは**矩形クロップ**です。検出した形状に沿ったマスクは作成されません。
  そのため、**余白をオブジェクト同士のすき間より大きくすると、隣のオブジェクトの
  一部が写り込む**ことがあります。余白はすき間より小さめに設定することをおすすめします。
- 検出は画像の全ピクセルを解析するため、グリッド近似だった旧バージョンより高精度です。
  非常に大きな画像（数千px四方など）では、解析に数秒〜十数秒かかることがあります。
- Node.jsのインストール、PNG限定、環境設定の許可など、追加の前提条件があります
  （上記「ピクセル単位モードの追加条件」を参照）。

## 使用例

### レイヤー単位モード

添付のような、バラバラに配置された図形・アイコンの集合が**すでに個別レイヤーとして
分かれている**場合：

1. すべての図形が入ったコンポをアクティブにする
2. しきい値を、まとめたい図形同士の間隔より大きく、離したい図形同士の間隔より小さい値に設定
3. **[実行]** → グループごとに新規コンポが作成される

### ピクセル単位モード

添付のような図形・アイコンの集合が**1枚のPNG画像（1レイヤー）として書き出されている**場合：

1. その画像レイヤーを選択する（Node.jsのインストールと、AE環境設定でのファイル/
   ネットワークアクセス許可を事前に済ませておく）
2. 検出モードで「ピクセル単位」を選択、背景の判定方法（自動など）を選ぶ
3. オブジェクト同士のすき間・コンポの余白を設定して **[実行]**
4. 解析が終わると、検出されたオブジェクトのかたまりごとに新規コンポが作成される
   （例：○のオブジェクトだけが入ったコンポ、◼︎のオブジェクトだけが入ったコンポ、
   という具合に分割されます）
