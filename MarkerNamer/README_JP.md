# C7_MarkerNamer.jsx（日本語）

音源レイヤーのマーカーに、ボタンを押すだけで名前を付けるパネル。マーカーのコピー＆ペースト機能（旧 MarkerCopy）も内蔵。
ライブ映像の `01_intro` `02_1A` `03_1B` … のような命名を、1マーカー1クリックで済ませるためのツールです。

---

## インストール

`C7_MarkerNamer.jsx`・`MarkerNamer.core.js`・`MarkerCopy.core.js` の **3つとも** を以下のフォルダに置いて、After Effects を再起動してください。

```
C:\Program Files\Adobe\Adobe After Effects <バージョン>\Support Files\Scripts\ScriptUI Panels\
```

**ウィンドウ → C7_MarkerNamer.jsx** でパネルが開きます（ドッキング可）。

> `MarkerNamer.core.js` などの .core.js が同じフォルダに無いとエラーになります。

---

## 基本の使い方

1. 音源レイヤーを選択
2. 再生ヘッドを最初のマーカーに置く
3. `intro` → `1A` → `1B` … とボタンを押していく

押すたびに名前が付き、再生ヘッドが次のマーカーへ自動で移動します。

| ボタン | 動作 |
|---|---|
| 名前ボタン（intro / 1A … / atk） | 今のマーカーに名前を付けて次へ |
| 自由入力 ＋ [付ける] | 入力した名前を付けて次へ |
| [◀ 前] / [スキップ ▶] | 名前を付けずに前後のマーカーへ移動 |
| [消去] | 今のマーカーの名前を消す |
| [連番振り直し] | 手で名前を直した後などに番号だけ振り直す |

「今のマーカー」＝再生ヘッドの位置、またはその直前にあるマーカーです。

---

## 連番のルール

- 名前を付けるたびに、時間順で `01_` `02_` … を自動で振り直します
- 名前の無いマーカーは数えません
- `atk` は番号なしのまま付きます
- 途中に差し込んだり消したりしても、後ろの番号は自動で詰まります

---

## マーカーコピー（旧 MarkerCopy）

パネル下部の「マーカーコピー」で、マーカーをクリップボード方式でコピー＆ペーストできます。
レイヤーマーカー・コンポマーカーをまたいで、または別コンポ間でも自由にコピーできます。

| 操作 | レイヤーを選択中 | 何も選択していない |
|---|---|---|
| **[Copy]** | そのレイヤーのマーカー（複数選択時は統合） | コンポマーカー |
| **[Paste]** | そのレイヤーへ（複数選択時は全レイヤー） | コンポマーカーへ |

クリップボードはパネルを閉じるまで保持されます。

### オプション

- **現在位置にペースト** — 先頭マーカーが再生ヘッドの位置に来るようシフトして貼る（OFF：元の時刻のまま）
- **既存マーカーを保持（追記）** — 既存マーカーを残して追記する（OFF：削除してから貼る）
- **レイヤーのイン点をオフセットに使う** — レイヤーのイン点を基準にした相対時刻で扱う（OFF：コンポの絶対時刻）

コピーされる情報：コメント、デュレーション、チャプター、URL、フレームターゲット、キューポイント名、ラベル

### よくある使い方

- 名前を付けた音源レイヤーのマーカー → コンポマーカーへ：音源レイヤーを選択して **[Copy]** → 選択を解除して **[Paste]**
- 別コンポへ：コピー後、コピー先コンポを開いて **[Paste]**

## カスタマイズ

`C7_MarkerNamer.jsx` の先頭で変更できます。

```js
var PRESETS  = ["intro", "1A", "1B", "1C", "2A", "2B", "2C", "D", "3C", "Theme", "Kanso", "outro", "atk"]; // ボタン
var OPTS     = {
    noNumber: ["atk"],   // 番号を付けない名前（"break" などを追加可）
    digits:   2          // 連番の桁数
};
```

---

## 注意事項

- 対象は選択中のレイヤーのマーカー（複数選択時は一番上のレイヤー）
- マーカーの色・長さなど、名前以外の情報は変わりません
- Undo（Ctrl+Z）に対応しています
