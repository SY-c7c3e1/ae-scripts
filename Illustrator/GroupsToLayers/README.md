# Groups to Layers

Illustrator用スクリプト。1つのレイヤーの直下にあるオブジェクト（グループ・
複合パス・単体パス・テキストなど種類を問わず）を、1個ずつ別々のレイヤーへ
分割する。

Illustrator標準の「レイヤーに分配」とほぼ同じ対象範囲だが、こちらはグループ
名を新レイヤー名に流用する命名処理や、選択中のオブジェクトのみ処理する
オプションを持つ。

## 使い方

1. Illustratorでドキュメントを開く
2. `GroupsToLayers.jsx` を実行（File → Scripts → Run Script File…）
3. ドロップダウンから対象レイヤーを選ぶ（サブレイヤーも階層表示で選べる）
4. 必要なら「選択中のオブジェクトのみ処理する」をON
   （OFFの場合、そのレイヤー直下にある全オブジェクトが対象）
5. [実行] を押す

新しく作られるレイヤーは元のレイヤーのすぐ上に積まれ、オブジェクト同士の
前後関係（重なり順）は分割後も維持される。

## 名前について

- グループに名前が付いている場合は、その名前がそのまま新しいレイヤー名になる
- 名前が未設定（空欄）の場合は「元レイヤー名_1」のように自動採番される
- 名前が重複する場合は末尾に " (2)" のように連番を付けて区別する

## 注意

- 対象にできるのは、選んだレイヤーの**直下**にあるオブジェクトのみ（グループの
  中身やネストされたグループの中身は対象外）
- 対象レイヤーがロックされている場合はロックを解除してから実行する
- 「処理後に元レイヤーが空なら削除する」がONで、かつ元レイヤーに何も残らな
  かった場合は、元レイヤー自体が削除される
